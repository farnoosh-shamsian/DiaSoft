# Computational Semantics for Homeric Greek (as part of DiaSoft)

Tools and experiments for discovering and cataloguing semantic fields (kinship, ruling, war, love, hospitality, …) in Ancient Greek, centred on Homer (Iliad + Odyssey) and the LSJ lexicon. The final goal is to use the clusters to extract words related to social relations for a project on frame semantics.

## Repository layout

| Folder                          | Content                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`homer_corpus/`**             | The source data: sentence-aligned Iliad and Odyssey CSVs (Greek text, English translation, treebank-derived lemma sequence per sentence), plus the full **AGLDT 2.1 dependency treebanks** (`iliad_treebank.xml`, `odyssey_treebank.xml`) carrying lemma + morphology + syntactic dependencies. Used by every Homer pipeline.                                                                                                                                    |
| **`lsj_semantic_search/`**      | Extraction of _predefined_ social-relations categories from the LSJ lexicon via contrastive sentence-embedding search over English glosses. Contains the LSJ source (`lsj_chicago.cex`), the notebook, results, and its own README.                                                                                                                                                                                                                             |
| **`cluster_gloss_embeddings/`** | **The current main approach for semantic _fields_.** _Emergent_ semantic fields for the full Homeric vocabulary: each lemma is represented by the sentence-embedding of its English definition (LSJ, with Ancient Greek WordNet fallback) and those vectors are clustered (UMAP + HDBSCAN, plus a Ward taxonomy). No predefined categories, no seed words. See its README for exact methods and results.                                                          |
| **`frame_induction/`**          | **Frame semantics from the dependency treebanks.** The step beyond fields: parses the AGLDT treebanks into predicate–argument tuples and induces candidate _frames_ by clustering verbs on their argument profiles (who fills their Subject/Object slots), with topic modeling as a syntax-aware component (type-scene discovery + per-book prevalence). This is where the frame-semantics goal is actually implemented. See its README.                          |
| **`word_sense_induction/`**            | **Senses before fields.** Every occurrence of every content word is embedded in context with GreBERTa, each lemma's occurrences are clustered into distinct senses, and the senses (not the lemmas) are then grouped into semantic fields — so a word with two meanings can sit in two fields at once. Addresses the one-vector-per-lemma limitation of the gloss and distributional pipelines. See its README.                                                  |
| **`contextual_clustering_greberta/`**  | **Corpus-only contextual clustering.** Semantic fields derived from GreBERTa contextual embeddings of the corpus alone — no glosses, no WordNet, no treebank. Type vectors are anisotropy-corrected (centring + top-2 PC removal) before UMAP/HDBSCAN and Ward clustering, with a glossed variant of the output for readability. A check on how far the corpus alone can go.                                                          |
| **`clustering_homer/`**         | Earlier _distributional_ attempts, kept for comparison: fastText embeddings trained on the Homeric corpus itself, clustered with HDBSCAN/Leiden (`semantic_fields_fasttext_HDBSCAN_Leiden.py`) and with CLTK normalization + UMAP + Ancient Greek WordNet labelling (`cltk_semantic_pipeline.py`), with their output folders. On 200k tokens of formulaic epic these cluster collocation rather than meaning — the motivation for the gloss-embedding approach. |

## Note on large files

The trained fastText models (`*.model`, `*.wv.vectors_ngrams.npy`, ~800 MB each) in `clustering_homer/*/` and `frame_induction/frame_output/` exceed GitHub's file size limit and are excluded via `.gitignore`; rerunning the corresponding script regenerates them.
